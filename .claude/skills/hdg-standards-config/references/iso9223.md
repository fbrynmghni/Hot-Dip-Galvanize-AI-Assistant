# ISO 9223 — Kategori Korosivitas & Laju Korosi Zinc

> **Status verifikasi:** laju di bawah adalah rentang referensi umum. Verifikasi
> ke ISO 9223/9224 yang dimiliki secara sah sebelum dipakai di produksi.

| Kategori | Lingkungan tipikal | Laju korosi zinc (µm/tahun) |
|---|---|---|
| C1 | Indoor kering | ≤ 0,1 |
| C2 | Rural, polusi rendah | 0,1 – 0,7 |
| C3 | Urban / pesisir ringan | 0,7 – 2,1 |
| C4 | Industri / pesisir | 2,1 – 4,2 |
| C5 | Industri berat / pesisir agresif | 4,2 – 8,4 |
| CX | Offshore / ekstrem | 8,4 – 25 |

## Estimasi umur — dan batasnya

Rumus kasar yang dipakai tool `estimate_durability`:

```
Umur (tahun) ≈ Ketebalan coating (µm) ÷ Laju korosi (µm/tahun)
```

**Ini konsumsi linear, dan itu penyederhanaan.** Definisi AGA untuk *time to
first maintenance* adalah saat ~5% permukaan menunjukkan karat baja dasar,
sehingga estimasi resmi AGA/GAA berbeda dari hasil rumus linear. Karena itu:

- Output tool **selalu berupa rentang** (pakai laju min dan max kategori),
  tidak pernah satu angka tunggal.
- Setiap jawaban mengarahkan ke tool resmi untuk kasus nyata:
  *Durability of Galvanizing Estimator* (GAA) dan *Life-Cycle Cost Calculator*
  (AGA/GAA) — **dirujuk via link, tidak di-clone**.
- Kategori C1 (`lo = 0`) menghasilkan pembagian nol pada batas terbaik. Tool
  mengembalikan `">100"`, bukan `Infinity` atau `NaN`.

## Default untuk konteks Indonesia

Iklim tropis lembap dan banyak lokasi pesisir. Bila user tidak tahu kategorinya:

- Default asumsi minimal **C3–C4**.
- **C5** untuk splash zone atau area dekat pantai.

Asumsi ini selalu dinyatakan eksplisit di jawaban, bukan dipakai diam-diam.
